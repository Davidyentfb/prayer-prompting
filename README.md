# Prayer Prompting — Astra Rebuild

The approved rebuild of [prayerprompting.com](https://prayerprompting.com), prepared November 11, 2026.

**Design:** Astra — luminous gold (#D4AF37) on deep black, with deep royal purple woven in as the companion colour (violet #7B2CBF, deep purple #3B1470, amethyst #A78BFA for glows; roughly 70/30 gold to purple). Purple carries the aura behind the gold orb, the hero's lower gradient wash, the Brain niches' backlight, the intake's progress line and selected state, and secondary accents.

## Files

- **`index.html`** — the complete built site as one self-contained file (all images inlined). Open it in any browser, or serve the repo with GitHub Pages.
- **`docs/blueprint.md`** — the full system blueprint: the Brain's repositories and canon, the intake flow, the Human Prayer Portal, verified helplines, the consent-first data system, push and email delivery, the charitable-trust tiers, and the machine-learning loop. Read this before building the production version.

## What the site contains

- The five-step intake (adapted from a quiz-funnel method): what brings you here → your tradition → the form you want → one of five care archetypes, each routed to a tailored room → optional email/push consent. A safety answer surfaces helplines immediately, before anything else.
- **The Brain** — a searchable library of attributed prayers, affirmations, teachings, and stories across twelve traditions, with the canon, the teachers, Neville Goddard and Reverend Ike, and the seven universal-law principles. Every item is attributed or it does not ship.
- **The Human Prayer Portal** — a real person prays for you; under a code of conduct (pray as asked, never preach, never handle crisis).
- **Helplines** — verified November 11, 2026; one tap from every screen; always free, never behind a tier.
- **Tiers** — Sanctuary (free forever), Supporter $5/month, Guardian $12/month, Congregations (partner tier). Operated by a charitable trust; prayer, human prayer, and crisis help are never charged.

## Honest scope

This build is the complete front end. In this static form, form submissions are a demonstration — no data leaves the page. The production build (per the blueprint) adds the server side: real push and email delivery per request, the live prayer-partner queue and moderation, payments, and the learning loop that improves the Brain only through human-approved additions.
